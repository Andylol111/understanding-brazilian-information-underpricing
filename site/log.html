    Verify

    Each row links to the one before it by a hash (SHA-256 of the previous row's hash plus the row's own text), so accidental edits or gaps within a file show up. GitHub's commit history records when each batch of rows was published. The log's files are in the repository.

    The button below downloads the file for the race you picked and recomputes its chain in your browser. It checks that the chain is consistent; it does not prove who wrote the rows or when.

    How the hash is computed

    Each file is one chain. Every line is JSON with sorted keys and a final "hash" field. The hash is sha256(prev_hash + line text without the hash field), where prev_hash is the previous line's hash (64 zeros for the first line). The check re-hashes the raw line text, so nothing is re-formatted.

    Rows tagged backfilled were rebuilt afterwards from the server's timeline files; rows tagged live were written as they were published; captured-live rows were read from the public feed before a restart rebuilt the history.

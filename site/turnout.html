How the model sees this

Statewide rows behind these numbers

Counts: official state and county election offices where they publish; the UF Election Lab compile for states that publish no open file (marked secondary); a few manual downloads. Expected votes: the registered live models' county inputs where a statewide race is modelled, otherwise 0.72 × the 2024 president two-party votes (MIT Election Data and Science Lab, CC0). Every derived figure on this page is unvalidated context and is not used by any model. Counts of different kinds are never added together unless they do not overlap, and a row that only sums some counties is a lower bound. The data files are refreshed in place.
